## Parte 3 - Correlaciones y multicolinealidad

**Responsable:** Pacitaugarte

**Carpeta:** `Parte 3 - Pacitaugarte`

En esta parte se estudian las correlaciones entre los predictores ambientales de la base de datos y se evalúa la multicolinealidad mediante el factor de inflación de la varianza (VIF).

El análisis incluye:
- Cálculo de la matriz de correlaciones de Pearson.
- Generación de un mapa de calor para visualizar las relaciones entre variables.
- Identificación de los 15 pares de variables con mayor correlación absoluta.
- Cálculo del VIF para los 24 predictores ambientales.
- Comparación del VIF con un conjunto exploratorio reducido de 7 predictores.

Los resultados se guardan en archivos CSV y PNG dentro de la carpeta correspondiente.

**Nota:** El conjunto reducido se utiliza únicamente para evaluar cómo cambia la multicolinealidad. No representa una selección definitiva de variables para el modelo de regresión.
